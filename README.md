# تحدي كرة القدم — Football Trivia (Arabic)

تطبيق Flutter عربي بالكامل (RTL) لأسئلة كرة القدم، مع تحدٍّ يومي وسلسلة أيام محفوظة محلياً وزر مشاركة النتيجة.

## البيئة

مثبّت على هذا الجهاز: **Flutter 3.44.8 / Dart 3.12.2** في `C:\src\flutter` — لكنه **غير مضاف إلى PATH**. أضِفه لجلسة PowerShell الحالية قبل أي أمر:

```bash
$env:Path = "C:\src\flutter\bin;$env:Path"
```

لإضافته بشكل دائم (مرة واحدة، ثم أعد فتح الطرفية):

```bash
[Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path','User') + ';C:\src\flutter\bin', 'User')
```

الـ JDK المستخدم هو المرفق مع Android Studio (**Java 25**)، ولذلك يعتمد المشروع **Gradle 9.1.0 + AGP 9.0.1 + Kotlin 2.3.20** — الإصدارات الأقدم من Gradle لا تدعم Java 25 وتفشل برسالة غامضة نصّها رقم إصدار Java فقط.

## البنية (Clean Architecture)

```
lib/
├── core/            # ثوابت، ثيم، أدوات، حاوية الاعتماديات
│   ├── constants/   # app_strings.dart · app_config.dart
│   ├── theme/       # app_colors.dart · app_theme.dart
│   ├── utils/       # day_key.dart · seeded_random.dart
│   └── di/          # injector.dart
├── domain/          # طبقة مستقلة عن Flutter بالكامل
│   ├── entities/    # Question · QuizResult · UserStats
│   ├── repositories/# عقود مجرّدة
│   └── usecases/    # GetQuizQuestions · GetDailyQuestions · UpdateStreak
├── data/            # تنفيذ العقود
│   ├── models/      # تحويل JSON ↔ كيانات
│   ├── datasources/ # assets JSON · SharedPreferences
│   └── repositories/
└── presentation/    # Provider + الواجهات
    ├── providers/   # QuizProvider · StatsProvider
    ├── screens/     # HomeScreen · QuizScreen · ScoreScreen
    └── widgets/     # PitchBackground · AnswerOption · TimerRing · ...
```

اتجاه الاعتماد: `presentation → domain ← data`. طبقة `domain` لا تستورد أي شيء من Flutter أو من الحزم الخارجية.

## المزايا

### الشاشات
- **الرئيسية**: بطاقة تحدي اليوم، إحصائيات (السلسلة/الأفضل/أعلى نتيجة)، اختيار الفئة، زر اللعب السريع.
- **الاختبار**: عدّاد دائري 20 ثانية لكل سؤال، شريط تقدّم، كشف فوري للإجابة مع شرح.
- **النتيجة**: ميدالية بنتيجة متحرّكة، نسبة الدقة، لقب حسب الأداء، مراجعة كل الإجابات.

### التحدي اليومي
أسئلة اليوم تُختار عبر مولّد عشوائي **حتمي** مبذور برقم اليوم منذ 1970 (`SeededRandom` في `core/utils`)، فيحصل كل المستخدمين على نفس المجموعة في نفس اليوم دون أي خادم. نقاط التحدي اليومي مضاعفة ×1.5 ويمكن لعبه مرة واحدة يومياً.

### السلسلة (Streak)
تُحفظ في `SharedPreferences` تحت المفتاح `user_stats_v1`:
- إكمال تحدي الأمس ثم اليوم ⇒ +1
- تكرار نفس اليوم ⇒ لا تغيير
- انقطاع يوم أو أكثر ⇒ العودة إلى 1 (مع الاحتفاظ بأفضل سلسلة)

اليوم يُحدَّد بالتاريخ المحلي (`yyyy-MM-dd`) فيبدأ عند منتصف الليل لدى المستخدم. المنطق كامل في `domain/usecases/update_streak.dart` ومغطّى باختبارات.

### المشاركة
زر **شارك النتيجة** في شاشة النتيجة يستخدم `share_plus` ويرسل نصاً عربياً يتضمن النقاط ونسبة الدقة والسلسلة. أُضيف بلوك `<queries>` في `AndroidManifest.xml` ليعمل على Android 11+.

## إضافة أسئلة

أضف عنصراً إلى `assets/data/questions.json`:

```json
{
  "id": 51,
  "category": "اللاعبون",
  "difficulty": "medium",
  "question": "نص السؤال؟",
  "options": ["أ", "ب", "ج", "د"],
  "answerIndex": 0,
  "explanation": "شرح اختياري يظهر بعد الإجابة."
}
```

الفئات تُستنتج تلقائياً من الملف — لا حاجة لتسجيلها في أي مكان آخر. اختبار `test/questions_asset_test.dart` يتحقق من عدم تكرار المعرّفات ومن أن كل سؤال يملك أربعة خيارات مختلفة.

## التصنيفات

عشرة تصنيفات. **النص يُطابَق حرفياً**، لذا انسخ الاسم كما هو — أي اختلاف بحرف واحد يُنشئ تصنيفاً جديداً في شريط الاختيار.

| التصنيف | ما يدخل فيه |
|---|---|
| `كأس العالم` | كل ما يخص المونديال: النتائج، الهدافون، الأرقام داخل البطولة، التنظيم |
| `البطولات القارية` | أمم أوروبا، كوبا أمريكا، أمم أفريقيا، كأس آسيا |
| `دوري أبطال أوروبا` | البطولة الأوروبية للأندية: الألقاب، الهدافون، نظام المسابقة |
| `الدوريات الكبرى` | الدوريات الخمسة الكبرى: نتائج المواسم، الألقاب، أرقام الدوري |
| `الكرة العربية` | **كل ما هو عربي** — أندية، منتخبات، لاعبون، مدربون |
| `اللاعبون` | المسيرة، الألقاب الشخصية، الجوائز الفردية، الانتقالات |
| `الأندية` | هوية النادي: التأسيس، الملعب، اللقب، الألوان، الديربي |
| `المدربون` | المدربون ومدارسهم وإنجازاتهم |
| `القوانين` | قوانين اللعبة، التحكيم، VAR، مواصفات الملعب والكرة |
| `لحظات وأرقام قياسية` | اللحظات الأيقونية والأرقام العابرة للبطولات |

### قواعد فضّ التداخل

عند احتمال وقوع السؤال في أكثر من تصنيف، تُطبّق القواعد بهذا الترتيب:

1. **`الكرة العربية` لها الأولوية المطلقة.** سؤال عن المغرب في المونديال ⇒ `الكرة العربية` لا `كأس العالم`. هذا مقصود: التصنيف الأهم لجمهور التطبيق يجب أن يبقى غنياً.
2. **البطولة تملك أرقامها.** الهداف التاريخي لكأس العالم ⇒ `كأس العالم`، وليس `لحظات وأرقام قياسية`.
3. **اللحظة الأيقونية تسبق البطولة.** «يد الله» و«ليلة إسطنبول» ⇒ `لحظات وأرقام قياسية` رغم أنهما من المونديال ودوري الأبطال.
4. **`الأندية` للهوية، `الدوريات الكبرى` للمنافسة.** ملعب برشلونة ⇒ `الأندية`؛ من فاز بالدوري موسم كذا ⇒ `الدوريات الكبرى`.
5. **الأرقام العابرة للبطولات** (أكثر مباريات دولية، أهداف في سنة تقويمية) ⇒ `لحظات وأرقام قياسية`.

## ملاحظات

- التطبيق يعمل بالكامل دون إنترنت.
- الخط: يُستخدم خط النظام العربي الافتراضي. لخط مخصص، أضف ملف `.ttf` إلى `assets/fonts/` وسجّله في `pubspec.yaml` ثم اضبط `fontFamily` في `AppTheme`.
- إعدادات التوقيع في `android/app/build.gradle.kts` تستخدم مفتاح التصحيح — استبدلها بمفتاح إصدار حقيقي قبل النشر على Google Play.
- تحذير `share_plus` بخصوص Kotlin Gradle Plugin أثناء البناء غير مؤثر حالياً؛ سيلزم ترقية الحزمة عندما تفرض إصدارات Flutter القادمة نظام Built-in Kotlin.
- `flutter doctor` يشير إلى نقص `cmdline-tools` في Android SDK. البناء يعمل بدونه، لكن لتثبيته: Android Studio ← Settings ← Languages & Frameworks ← Android SDK ← SDK Tools ← *Android SDK Command-line Tools*.
